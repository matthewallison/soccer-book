# Reaction Trainer

Use the standalone reaction-training app for the most reliable full-screen behavior on iPhone and other mobile browsers.

[Open Reaction Trainer](reaction-trainer.html){ .md-button .md-button--primary }

The trainer lets you:

- choose any 2+ colors from the pool;
- set the cue interval;
- run a full-screen color sequence;
- guarantee that the next color is different from the current one;
- tap the color screen anywhere to stop.

For a home-screen-style experience on iPhone, open the trainer in Safari and use **Share → Add to Home Screen**.
